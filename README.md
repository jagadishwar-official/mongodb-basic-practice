# MongoDB Basic Practice

This repository contains my MongoDB basic practice work, covering database creation, CRUD operations, query operators, and a small Library System use case.

## 📌 Topics Covered

- Database and Collection Creation
- `insertOne()`
- `insertMany()`
- `find()`
- Filtering Documents
- `updateOne()`
- `updateMany()`
- `deleteOne()`
- `deleteMany()`
- MongoDB Query Operators:
  - `$gt`
  - `$lt`
  - `$in`
  - `$and`
  - `$or`
  - `$exists`

## 🗄️ Database Practice

### Database
`studentDB`

### Collection
`students`

The student collection was used to practice:

- Inserting student records
- Reading and filtering student data
- Updating student status
- Deleting documents
- Searching using query operators

## 📚 Library System

I also created a small Library System use case using a `books` collection.

### Operations Practiced

- Insert books
- Display books
- Search books by category
- Search books using price conditions
- Update book availability
